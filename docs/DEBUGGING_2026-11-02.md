## Условия запуска обновлённой версии

1. **Node.js 22.12+**.
2. **MongoDB replica set или sharded cluster**; MongoDB Atlas подходит. Автоматического перехода к частичным списаниям без транзакций больше нет.
3. Для проверки веб-прав нужны `GUILD_ID` и действующий токен бота с доступом к серверу. Административный запрос не продолжится, если Discord не подтвердил членство и роли.
4. Для старых персонажей без публичных идентификаторов предусмотрен `npm run migrate:public-ids`. Новые персонажи получают их автоматически.
5. Квитанции в `operation_receipts` не имеют TTL: удаление квитанции позволило бы позднему повтору снова применить операцию.
6. Незавершённые операции старой версии, выполненные до появления квитанций, требуют сверки по данным и логам. Новый код не угадывает, было ли историческое списание; старые захваты автоматически не повторяются.

CI добавлен в `.github/workflows/ci.yml`; сам удалённый workflow запустится после публикации изменений в репозитории. Проверка реальных Discord interaction payloads, OAuth и ролей на рабочем сервере остаётся проверкой развёртывания; локальные проверки используют настоящую БД и управляемые Discord-ответы.
