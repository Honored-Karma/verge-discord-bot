# Verge TRP Release Checklist

Чек-лист для проверки перед каждым обновлением или публичным релизом.

---

### 1. Конфигурация и переменные окружения (.env)
- [ ] `NODE_ENV=production` задан.
- [ ] `SESSION_SECRET` сгенерирован (длина $\ge 32$ символов, не дефолтный).
- [ ] `WEB_BASE_URL` использует `https://` и совпадает с публичным доменом.
- [ ] `DISCORD_REDIRECT_URI` использует `https://` и совпадает с доменом.
- [ ] В `.env` и в кодовой базе отсутствуют закоммиченные секреты.
- [ ] `.env` добавлен в `.gitignore`.

---

### 2. База данных (MongoDB Atlas)
- [ ] Пользователь MongoDB имеет права `readWrite` только к базе `discord_bot`.
- [ ] Сетевой доступ (Network Access / IP Whitelist) разрешает IP-адрес сервера.
- [ ] Выполнен бэкап базы перед релизом (`mongodump`).
- [ ] Проверены уникальные индексы (`players`, `applications`, `wiki_articles`, `sessions`).

---

### 3. Сборка и тесты
- [ ] Выполнен `npm test` — все тесты (100% green).
- [ ] Выполнен чистый билд `npm run build` без ошибок.
- [ ] Отсутствуют устаревшие артефакты в `web/dist`.
- [ ] `npm audit --omit=dev` проверен на отсутствие уязвимостей критического и высокого уровня.

---

### 4. Discord Интеграция
- [ ] Server Members Intent и Message Content Intent активны в Developer Portal.
- [ ] OAuth2 Redirect URL зарегистрирован в Developer Portal.
- [ ] Бот успешно подключается к шлюзу Discord.
- [ ] Слэш-команды задеплоены на сервере.

---

### 5. Безопасность и социальные превью
- [ ] HSTS активен для HTTPS.
- [ ] Content-Security-Policy (CSP) не блокирует легитимные ресурсы.
- [ ] Проверены `/robots.txt` и `/sitemap.xml`.
- [ ] Проверена генерация метатегов OpenGraph (`metaInjector`) на реальном домене.
- [ ] Приватные персонажи и инвентари защищены от доступа неавторизованных пользователей.
- [ ] Доступ к панели `/admin` открыт только пользователям с соответствующими ролями.
