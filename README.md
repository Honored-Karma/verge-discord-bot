## ✨ Возможности

- **60 слэш-команд и 3 действия в меню сообщения** — регистрация, тренировки, экономика, администрирование и отыгрыш
- **[Профили для отыгрыша](docs/TUPPER.md)** — создание, изменение и удаление своих профилей через `/vupper`: имя, аватар файлом или ссылкой и маркеры
- **Система слотов** — до 3 персонажей: два стандартных слота и третий по выдаче администрации (`/grant-slot`)
- **AP / SP прогрессия** — очки способностей и очки стилей с множителями и бонусами за ранг/активность
- **Двойная валюта** — KRW и YEN, обмен по курсу 1 ¥ = 9.4 ₩
- **Еженедельные зарплаты** — автоматические выплаты по организации и рангу (cron)
- **Ролевая система прав** — ADMIN_IDS, LIMITED_ADMIN_ROLE_IDS, GIVE_STYLE_ROLE_IDS
- **Логирование команд** — запись в БД + пересылка в лог-канал (`/log-enable`, `/log-disable`)
- **Профиль с пагинацией** — 4 страницы: основная, AP/SP, стили, баланс + история
- **Красивые embed-ы** — баннеры, прогресс-бары, кнопки навигации
- **MongoDB Atlas** — автоматическая инициализация 10 коллекций с индексами

## 🚀 Быстрый старт

### Требования
- **Node.js** 22.12+
- **MongoDB Atlas** (бесплатный кластер)
- **Discord Bot Token**

### Установка

```bash
git clone https://github.com/your-username/verge-discord-bot.git
cd verge-discord-bot
npm ci --include=optional
cp .env.example .env   # заполните своими значениями
npm run deploy          # зарегистрировать команды в Discord
npm start               # запустить бота
```

Подробнее: [QUICKSTART.md](QUICKSTART.md)

Для Linux-контейнера устанавливайте зависимости из `package-lock.json`:
`npm ci --omit=dev --include=optional`. Нативная библиотека отрисовки проверяется
в `postinstall`; вручную проверку можно запустить командой `npm run check:native`.
Если старый образ падает с `Cannot find module '@napi-rs/canvas-linux-x64-gnu'`,
пересоберите контейнер с актуальным lock-файлом, чтобы установилась Linux-сборка.

### 🥋 Тренировка и стили
| Команда | Описание |
|---------|----------|
| `/train-ap` | Тренировка через модальное окно (AP, кулдаун 5ч) |
| `/train-sp` | Выбор изученного стиля и тренировка через форму (SP, кулдаун 5ч) |
| `/social-rp` | Социальная сцена через модальное окно (AP, кулдаун 12ч) |
| `/styles-list` | Список стилей с пагинацией |
| `/add-style` | Создать стиль (админ) |
| `/delete-style` | Удалить стиль (админ) |
| `/give-style` | Выдать стиль игроку |
| `/remove-player-style` | Убрать стиль у игрока |

Тренировки и `/social-rp` доступны в РП-каналах, включая их ветки.
Бот проверяет фактические права самого канала: `@everyone` не может его видеть,
а роль `RP_ROLE_ID` (по умолчанию `PLAYER_ROLE_ID`, `1431761095319879892`) может.
Учитываются базовые права ролей и переопределения канала; для веток проверяется
родительский канал. Права категории не заменяют отдельные настройки канала.
Права проверяются при вызове команды и отправке формы. Если права
проверить не удалось, активность отклоняется без штрафа.
За вызов вне РП-канала списывается до 10 AP (`/train-ap`, `/social-rp`)
или до 10 SP (`/train-sp`) без ухода ниже нуля. При вызове `/train-sp` штраф
применяется к самому прокачанному изученному стилю; при отправке уже открытой
формы — к выбранному стилю. Без изученных стилей списание SP равно нулю.

Повторные тренировки AP и SP в одном канале имеют общий счётчик на персонажа:
каждый повтор умножает итоговый множитель ещё на 0,8 (100%, 80%, 64%, 51,2%…).
Учитываются только успешно завершённые тренировки; `/social-rp` не увеличивает
счётчик. Непустое сообщение от пользователя в другом канале того же сервера
сбрасывает снижение для активного персонажа. Тренировка в новом канале также
начинается без снижения. Счётчик сохраняется при перезапуске бота.

## 🔧 Конфигурация (.env)

```env
DISCORD_TOKEN=...          # Токен бота (обязательно)
CLIENT_ID=...              # ID приложения (обязательно)
MONGODB_URI=...            # MongoDB URI (обязательно)
GUILD_ID=...               # ID сервера (для guild deploy)
ADMIN_IDS=id1,id2          # ID полных админов
LIMITED_ADMIN_ROLE_IDS=... # Роли для add-ap, add-sp и т.п.
GIVE_STYLE_ROLE_IDS=...    # Роли для give-style
SALARY_CRON=0 12 * * 1    # Расписание зарплат (по умолчанию: пн 12:00 UTC)
SALARY_LOG_CHANNEL_ID=...  # Канал для отчёта о зарплатах
```

Служебные slash-команды регистрируются с правом Discord **Administrator** и отключены в личных сообщениях. `send-json`, `render-ui`, объявления и управление каталогом дополнительно проверяют полный административный доступ при выполнении. Для ГМов, анкетологов и модераторов сохраняются проверки назначенных ролей для их команд. Если у такой роли нет **Administrator**, разрешите ей нужные команды отдельно: **Настройки сервера → Интеграции → бот → команды**. Настройки Discord не заменяют проверку роли внутри бота.

Полный список — см. [.env.example](.env.example)

Подробное описание обновления экономики, обучение игроков и руководство администрации — в [инструкции от 14 августа 2026](docs/UPDATE_2026-08-14.md).

## 🐛 FAQ

**"Unknown interaction"** — бот не успевает ответить за 3 сек. Используйте `deferReply()`.

**MongoDB connection error** — проверьте IP в Atlas Network Access и корректность URI.

**Команды не видны** — выполните `npm run deploy` и подождите до 15 минут.
